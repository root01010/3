# Лабораторна робота №3 — Автосалон

Тема: Цикли. Багаторазові обчислення та структури даних у C#.

Проєкт реалізує консольну програму для автосалону. У програмі використано:

- цикли `for`, `while`, `do-while`, `foreach`;
- `break` та `continue`;
- список `List<Car>` для зберігання автомобілів;
- функції для меню, пошуку, статистики та додавання авто;
- перевірку введення користувача;
- кольори у консолі.

## Запуск

```bash
cd AutosalonLab3
dotnet run
```
